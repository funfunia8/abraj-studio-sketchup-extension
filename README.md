# ABRAJ STUDIO – SketchUp Furniture Extension

## Project Vision
ABRAJ STUDIO is a parametric furniture engineering extension for SketchUp 2026 designed to bridge the gap between design and manufacturing.

The extension is not a simple furniture library or 3D viewer. It is a production-oriented design system where changing dimensions, material, hardware, or layout automatically updates the generated 3D object, shop drawings, cut list, BOM, and fabrication-related data.

## Core Objective
A user can create a base cabinet or furniture system with a few parameters and the extension will generate:
- 3D geometry
- 2D shop drawings
- cut list
- bill of materials
- material usage
- accessories and hardware list
- cost estimates and reporting

## Executive Summary
This project begins with the most crucial mandatory milestone: a fully parametric base cabinet. Once the base cabinet engine works correctly, the same architecture can be extended into:
- kitchens
- wardrobes
- bedrooms
- tables
- chairs
- sofas
- integrated cabinet systems

## Architectural Direction
The system will be built around four connected layers:
1. Product data layer
2. Parametric geometry layer
3. Reporting layer
4. SketchUp integration layer

## Phase 1 Completion
The first completed step includes the base cabinet core model, parameter validation, part generation, shelf position logic, cut list generation, BOM generation, and manufacturing data preparation.

## Future Roadmap
- Phase 1: Base Cabinet Engine
- Phase 2: 2D drawings and UI controls
- Phase 3: Materials and hardware libraries
- Phase 4: Manufacturing exports and DXF-ready data preparation
- Phase 5: Pricing and reports
- Phase 6: Expanded furniture categories
- Phase 7: Testing, packaging, documentation

## Repository Status
This repository currently contains the initial project structure and the core engine needed for the first functional cabinet model.

## Target Use Case
The extension is intended for professional furniture design workflows where the final result must be fabrication-oriented and parametric, not purely visual.

## Long-Term Goal
Create a professional SketchUp extension capable of converting furniture concepts into manufacturable engineering data while keeping the design linked to the production process.
